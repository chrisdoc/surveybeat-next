- **Session cookie:** `__Host-surveybeat-session` is `HttpOnly; Secure; SameSite=Lax; Path=/` with no `Domain` and lasts 30 days. The `__Host-` prefix keeps it off `pr-<n>.submit.` and other subdomains. POSTs from a foreign `Origin` get 403.
- **Per-request check:** the access token is verified locally and refreshed when it has expired. The request is then denied if the session is revoked or the user's Person is no longer active. Logout records the session as revoked before redirecting to WorkOS, so a copied cookie stops working on the next request. A test covers exactly that.
- **Where the deny list lives** (recorded in ADR 0010):
  - Revoked sessions are in **D1**, keyed by session id. One WorkOS session moves between Organizations when it is refreshed, and a session with no Organization yet has no Durable Object to ask.
