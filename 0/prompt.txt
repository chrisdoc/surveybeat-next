## Findings

**MAJOR — the model input uses the stored N, not the current N** (`Organization.ts:~1011`).
- The guard calls `enforceEffectiveNOnResult(stored, N)`, but `buildThemesInput(stored, ...)` is given the unenforced `stored`.

- The retry window is up to 24 hours, so this is realistic. It breaks ADR 0004 and the privacy invariant that every aggregate obeys N.
- Fix: compute `const effective = enforceEffectiveNOnResult(stored, dirState.minimumGroupSize)` once and pass `effective` to both `shouldRequestThemes` and `buildThemesInput`. Add a test where N is raised between request and attempt.

**MAJOR — the adapter test only covers the give-up path** (`ThemesTestRoutes.ts`, `Organization.test.ts:276+`).

**MINOR — the alarm is not re-armed after the lease** (`Organization.ts:~1013`).
- `repairAlarm` runs only at the end of step 3. After the lease is taken, the alarm may point at nothing or at a later job.
- If the object dies mid-call, recovery relies on the platform retrying the in-flight alarm.
- Fix: call `yield* repairAlarm()` after the lease transaction, so the alarm is armed for lease expiry.
