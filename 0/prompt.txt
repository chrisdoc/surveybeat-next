## Scope (summary; #40 is binding)
- **Question types:**
  - rating 1–5 with labelled ends, plus an optional "Want to say more?" comment;
  - single choice;
  - long text (≤ 1,000 characters).

  The type is an open union (a Schema TaggedUnion), so eNPS and multiple choice can be added later.
- **Question and Question version are both modelled.** Answers will point at a version. In R1 each Question has exactly one version, and a Question that has Answers can't be edited. Expose an `hasAnswers` check now; it always returns false until slice 09.
- **The weekly team health Template**, with the Dimensions workload, psychological safety, clarity and recognition. Write sensible, short, neutral Question texts, about 5–6 questions, with at least the first one a rating. The Template lives in code.
- **The Pulse editor:**
  - create a Pulse for a Team from the Template;
  - add Questions (from the Template, or new ones);
  - remove and reorder Questions;
  - show the estimated answer time;
  - warn when there are more than 7 Questions or the answer time goes over about 90 seconds;
  - note that one-tap answering needs a rating Question first.
- **Pulse settings:**
  - the Team;
  - the weekly day and time, between 06:00 and 21:00 local;
  - an answer window of 1–6 days, default 3;
  - 0–2 reminders, default 1;
  - anonymous mode only;
  - Invitation Distribution only.

  Model Distribution and Anonymity mode as fields with one allowed value each.
- A warning, not a block, when the Team has fewer members than N.
- **Who may do what:** the permission table decides. Leads and admins of that Team may create and edit its Pulses. Add these actions to `PERMISSIONS` with table tests.
- **Storage:** in the Organization DO, with a new migration.
- **Endpoints:** add the API endpoints and classify every one in `privacyRegistry`. None of them returns Result data.
- **Web:** minimal screens using the message catalog, Tailwind and Base UI: a Pulse list per Team and the Pulse editor.
- **Out of scope:** Rounds, scheduling and sending, which are slice 07.
