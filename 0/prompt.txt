  Summary:
  - **Scanners:** Microsoft Defender Safe Links scans every URL before delivery and detonates URLs it has no reputation for. It is on by default through Built-in protection. Its GET and HEAD requests have been seen coming from headless Chrome on AS8075, which means it runs JavaScript; this comes from a GitHub issue, not Microsoft docs. Mimecast and Proofpoint sandbox suspicious messages before delivery. All of them, plus Barracuda and Gmail, check links again at click time. Apple Mail Privacy Protection does not follow links.
  - **Vendors:** SurveyMonkey and Qualtrics both document that recording the answer on the click lets scanners answer first. Qualtrics fixes it with reCAPTCHA v3. Medallia uses bot detection plus "interaction gating": it saves only after a real click, scroll or keypress. For magic links, WorkOS moved to codes, Stytch uses bot detection, and Supabase and Auth.js use a GET page with a POST. I found no primary docs for Delighted.
  - **Standards:** RFC 9110 §9.2.1 says a GET must not trigger an action like recording an answer, and RFC 8058 requires a POST for one-click unsubscribe for the same reason. Gmail requires RFC 8058 from senders above 5,000 messages a day, which applies to our reminder opt-out.
  - **Recommendation:** the rating link GET opens the answer page with the tapped value preselected and writes nothing; HEAD gets a 200. The answer is saved by a POST on the member's first real interaction, never on page load. No tentative answers stored on the server, no single-use tokens, no third-party bot detection. Scanner heuristics are for metrics only.
  - **Decision for the product owner:** the §5.1 wording "each rating value is a link that records the answer" needs to change. The cost is that a member who taps a value and then leaves without touching the page loses that answer.
  - **Gaps:** the Medallia and Mimecast details come from search-index summaries because both sites blocked the fetcher. No scanner vendor documents whether its sandbox clicks buttons or submits forms; that rests on field reports.
